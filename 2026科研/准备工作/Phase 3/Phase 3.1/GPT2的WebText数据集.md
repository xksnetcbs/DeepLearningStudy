# GPT2的WebText数据集

**WebText 是 GPT2 论文为语言模型训练构建的网页文本数据集。作者希望从广泛、多样的自然文本中获取任务示范，并用 Reddit 外部链接的用户反馈作为低成本的筛选线索。** 理解它，有助于回答“GPT2 从哪里接触到问答、解释和翻译等文本模式”。

本文依据 [[language-models-GPT2.pdf]] 整理，保留原论文的数据构建事实、数值和限制；关于这些文本为何可能产生任务能力的机制解释，另见 [[语言模型如何从文本中学习多任务]]。本笔记讨论的是论文使用的 WebText 初步版本，不把它当作所有网页数据集的通用定义。

## 为什么需要多样的自然任务示范

过去不少语言模型主要使用新闻、维基百科或小说。单一来源有明显的文体与主题限制。为了接触更多自然存在的任务形式，作者希望训练文本足够大，也足够多样。

Common Crawl 的规模很大，但原文第 2.1 节认为其中存在大量质量较差、难以理解的内容。直接把数据加大，不一定能使模型接触到更多有用的文本关系。

## WebText的具体构建方式

作者采用了 Reddit 用户已经做过的筛选作为低成本质量线索：抓取**获得至少 3 karma 的 Reddit 外部链接所指向的网页**。karma 是启发式信号，意味着一些用户认为链接有趣、有教育意义或好笑；它不是专业标注，也不是事实正确性的保证。

| 步骤     | 原文给出的安排                      | 需要怎样理解                           |
| ------ | ---------------------------- | -------------------------------- |
| 收集链接   | 约 4,500 万个满足条件的外部链接          | 这是候选链接数量，不是最终训练文档数量              |
| 提取正文   | 结合 Dragnet 与 Newspaper       | 尽量从 HTML 中提取文本内容                 |
| 时间截断   | 本文使用的版本不含 2017 年 12 月之后创建的链接 | 应按链接创建时间理解，不能替换成“所有网页内容都在此时之前写成” |
| 清理     | 去重及一些启发式清洗                   | 原文没有完整列出每条清洗规则                   |
| 最终规模   | 略多于 800 万篇文档，约 40 GB 文本      | 本文报告的是 WebText 的初步版本             |
| 排除维基百科 | 删除全部 Wikipedia 文档            | 减少与常见评测数据来源重叠，便于分析               |

在翻译实验部分，作者还说明他们在过滤时刻意排除了非英语网页。但语言检测仍发现约 10 MB 法语文本。英语网页可以引用法语、解释法语短语，所以“排除非英语网页”并不等于“文本中每一句都是英语”。

## 为什么英语网页也能教翻译

论文表 1 展示了自然存在的英法互译片段：人们引用一句法语，然后用英语解释含义，或在英语叙述中给出某种表达的法语对应形式。这些是原论文展示的真实文本片段，不是为了本笔记另行构造的教学例句；具体片段可在 [[Language Models are Unsupervised Multitask Learners_完整中文翻译#2.1 训练数据集|译文第 2.1 节的表 1]] 中核对。

这种文本对模型而言仍然只是要预测的序列；但预测解释或译文时，可能需要建立两种语言间的对应关系。这直接支持作者关于“自然示范”的动机。

它没有证明这些零散文本与专业平行语料一样有效，也没有证明可以在没有任何跨语言线索的情况下得到高质量翻译。本文的翻译分数仍然很低。
