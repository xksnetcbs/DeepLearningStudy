# GPT1论文总结

**核心结论：先从无标注文本中学习语言模型，再用标注数据微调，同一套 Transformer 主体就能适配多种语言理解任务。**这篇论文的贡献主要是整体方案和跨任务实验证据。

## 解决什么问题

文本丰富，但问答、分类等具体任务的人工标注数据稀缺。已有词嵌入主要迁移词级信息，作者希望学习更高层次、能够利用上下文的通用表示，减少各任务的架构定制。

## 方法全貌

| 步骤 | 做什么 | 详细说明 |
| --- | --- | --- |
| 预训练 | 用 BooksCorpus 连续文本训练下一个词元预测 | [[生成式预训练]] |
| 微调 | 用任务标签、评分或正确选项继续更新模型 | [[生成式预训练与判别式微调的区别]] |
| 输入适配 | 将句子对、背景与答案等转换为词元序列 | [[GPT1的文本蕴含相似度与问答任务]] |

两阶段复用一个 12 层 Transformer 主体；输入嵌入、注意力与输出层见 [[GPT1模型架构]]。微调可保留辅助语言目标，其收益和局限见 [[GPT1微调的辅助语言建模目标]]。

## 实验发现

| 结果 | 可以说明什么 |
| --- | --- |
| 12 个数据集中的 9 个达到当时最佳结果 | 方法适用于多类语言理解任务，但不保证所有任务均最优 |
| Story Cloze：77.6 → 86.5；RACE：53.3 → 59.0 | 相比当时表中最佳结果，分别提高 8.9 和 5.7 个百分点 |
| 去掉预训练，表 5 平均分：74.7 → 59.9 | 在该设置下，预训练对任务表现有明显贡献 |
| 用单层 LSTM 替代 Transformer：74.7 → 69.1 | 这一框架下 Transformer 整体更好，不代表所有架构与配置的普遍结论 |
| 迁移更多预训练层总体带来收益 | 可迁移信息不仅存在于词嵌入层 |

模型在 RTE 上为 56.0，低于表中多任务 BiLSTM 的 61.7；MRPC、SST-2 也未刷新最佳结果。不能将“9/12”解释为任何任务都有效。

## 零样本分析与证据边界

作者用预训练模型配合任务专用评分规则，进行无需监督微调的分析。例如，SST-2 在文本末尾添加 `very`，比较 `positive` 与 `negative` 的概率。表现随预训练改善，为模型学到任务相关信息提供线索。

这些启发式解法不等同于现代聊天模型的指令遵循。消融实验说明训练阶段或组件对结果有贡献，但没有直接确定哪些层学到了语法、世界知识或具体推理机制。

## 如何判断论文的信息量

| 阅读目的 | 正文覆盖情况 |
| --- | --- |
| 理解方案 | 给出了训练目标、任务输出和输入适配的骨架 |
| 学习底层原理 | 注意力、层归一化、GELU 等依赖已有文献，没有逐项推导 |
| 精确复现 | 给出主要超参数，仍需核对具体实现与各任务的数据处理 |

因此，方法叙述简洁、前置原理展开较少，实验覆盖面较广。其贡献在于验证预训练与迁移路线，并非提出新的注意力公式；它适合带着具体问题阅读，也需要补充前置知识。

## 原文数字的注意点

引言称 GLUE 提升 5.5%，但表 4 的 72.8 与 68.9 相差 3.9 分；消融正文写下降 14.8%，但 74.7 到 59.9 是下降 14.8 分。阅读时区分分数差值与相对百分比。
