# GELU激活函数

## 是什么

GELU 全称 Gaussian Error Linear Unit，中文为高斯误差线性单元，是一种逐元素作用的非线性激活函数。它不是独立的网络层架构，也没有自身需要学习的参数。

激活函数放在线性变换之间，使网络能表达非线性关系。如果只连续叠加线性变换，整体仍可合并为一次线性变换。

## 定义与直觉

$$
\operatorname{GELU}(x)=x\Phi(x),
$$

其中 $\Phi(x)$ 是标准正态分布的累积分布函数：

$$
\Phi(x)=\frac12\left[1+\operatorname{erf}\left(\frac{x}{\sqrt2}\right)\right].
$$

输入乘以介于 0 与 1 之间的平滑权重 $\Phi(x)$。输入越大，权重越接近 1；输入越负，权重越接近 0。这是确定性的计算，不意味着每次随机保留或丢弃输入。

## 曲线长什么样

![[GELU函数曲线.png]]

蓝色实线为精确 GELU，橙色虚线为 $\operatorname{ReLU}(x)=\max(0,x)$。左图展示整体，右图放大零附近。

- 很负的输入：输出从负侧接近 0。
- 负数靠近零的区间：出现小凹谷，最低点约为 $(-0.752,-0.170)$。
- 零点：函数通过 $(0,0)$，斜率为 $0.5$，没有 ReLU 在零点的折角。
- 很正的输入：输出越来越接近 $y=x$。

GELU 是光滑的，但不是全程单调递增：负半轴先下降到最低点，再上升。曲线也不是正态分布的钟形密度曲线。

| 输入 $x$ | $\Phi(x)$ 约值 | GELU 输出约值 | ReLU 输出 |
| --- | ---: | ---: | ---: |
| -2 | 0.0228 | -0.0455 | 0 |
| -1 | 0.1587 | -0.1587 | 0 |
| 0 | 0.5000 | 0 | 0 |
| 1 | 0.8413 | 0.8413 | 1 |
| 2 | 0.9772 | 1.9545 | 2 |

这些值由精确定义计算并四舍五入，不是实验性能数据。

## 在GPT1中的位置

GPT1 前馈网络的流程是：**768 维 → 线性变换到 3,072 维 → GELU → 线性变换回 768 维**。

GELU 作用于隐藏向量的每个分量，不改变向量维度；它提供非线性，自注意力负责位置间的信息交互。完整前馈公式见 [[GPT1模型架构#逐位置前馈网络]]。
