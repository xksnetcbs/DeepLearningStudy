# 生成式预训练

**GPT1 的生成式预训练，就是让模型读取无人工任务标签的连续文本，通过预测下一个词元学习参数，供后续任务使用。**本笔记解释这一阶段内部如何训练；两个阶段的整体对照见 [[生成式预训练与判别式微调的区别]]。

## 无监督、生成式、预训练分别指什么

无监督预训练是一类训练安排，不只限于预测下一个词元。GPT1 采用的是自回归语言建模，也就是根据前文预测下一个词元。

“生成式”描述学习预测和生成文本的目标；“无监督”强调无需人工任务标签；“预训练”说明这个阶段发生在下游任务微调之前。在这篇论文中，这些词从不同角度描述同一个训练阶段，不能因此认为所有无监督预训练都是这种方法。

## 没有人工标签，目标从哪里来

原始文本自己提供答案。例如原文是“今天的天气很好，我们去公园散步”，就能构造以下预测关系：

| 已知上下文 | 从原文取得的目标 |
| --- | --- |
| 今天的天气 | 很好 |
| 今天的天气很好，我们去 | 公园 |

这是便于理解的词语级示意。实际模型处理分词器输出的词元，词元可能是词、词的一部分或标点，并不固定对应一个完整词语。

没有人工提供的情感类别或问答标签，不等于没有训练目标。目标是原文中真实出现的下一个词元。这种由数据自身构造监督信号的做法，通常称为自监督学习；原论文使用的是“无监督预训练”这一表述。

## 一次训练在做什么

1. **准备输入与目标。** 对原始文本进行清理和分词，取一段连续词元。以各位置之前的文本为上下文，以该位置的真实词元为预测目标。
2. **计算上下文表示。** 将输入词元与位置转换为向量，经 Transformer 各层计算。因果注意力掩码阻止某个位置看到后面的答案；它仍可使用此前的上下文。
3. **输出概率分布。** 模型为词表中的每个候选词元分配概率。例如，在“我们去”之后，对“公园”“学校”等候选给出不同概率。
4. **计算损失。** 检查模型给真实目标词元的概率。真实答案的概率越低，惩罚越大。
5. **更新参数。** 通过反向传播求出损失对参数的梯度，由优化器调整参数。训练不断重复，使模型整体上更善于预测训练文本的后续内容。

上述是逻辑顺序。实际训练可以借助因果掩码，在一次前向计算中并行计算一段文本多个位置的预测和损失，并非必须逐个位置单独调用模型。训练时使用真实文本上下文，也不需要把模型刚生成的词作为下一步训练输入。

## 数学目标及其直觉

论文最大化真实下一个词元的对数概率：
$$
L_1(U)=\sum_i\log P_\Theta(u_i\mid u_{i-k},\ldots,u_{i-1}).
$$
等价地，可以最小化负对数似然损失：
$$
\mathcal L=-\sum_i\log P_\Theta(u_i\mid u_{i-k},\ldots,u_{i-1}).
$$
其中 $u_i$ 是原文中真实的目标词元，$k$ 为上下文窗口大小，$\Theta$ 为模型参数。实践中也可对这些损失取平均。

例如，真实目标为“公园”。如果模型赋予它的概率为 0.2，这个位置的损失为 $-\ln(0.2)\approx1.609$；如果概率提高到 0.8，损失变为 $-\ln(0.8)\approx0.223$。因此，训练会鼓励模型给真实后续词元更高的概率。以上概率仅为示意，不是论文中的实验数据。

同一上下文可能有多个合理续写，但一个训练样本只提供其中实际出现的一种。模型从大量不同样本中学习统计规律，并非学习每个上下文只有一个合法答案。

## 为什么预测词元可能帮助理解语言

预测目标本身很简单，但预测所需的信息可以很复杂。为了降低损失，模型可能学会利用语法、常见搭配、事实信息、指代关系及较远的上下文。

| 示例上下文 | 可能有助于预测的信息 |
| --- | --- |
| “他昨天已经……” | 时态表达与语法搭配 |
| “法国的首都是……” | 训练文本中的事实知识 |
| “小明把书借给小红。她……” | 人物及指代关系 |
| 故事前段出现线索，后段出现转折 | 较长距离的上下文联系 |

这些是解释训练机制的示意，不是模型必然掌握相应能力的证明。模型直接优化的是词元预测损失，而不是一个叫作“理解程度”的分数。实际是否获得有用能力，要通过下游任务或其他实验检验。

## 训练后得到什么

主要产物是模型参数，包括词元嵌入、位置嵌入、注意力和前馈网络中的权重等。输入文本时，模型利用这些参数计算随上下文变化的内部表示和预测概率。

这些参数可以编码从数据中学到的规律，但不是一本能逐条检索、保证正确的知识库。模型也可能记忆文本、依赖表面统计关联，或者学到错误信息。

## GPT1的训练设置与证据

实际训练时，作者随机采样长度为 512 个词元的连续文本序列，每批 64 条，使用 Adam 优化器训练 100 个轮次。这些设置决定如何执行上述训练，而不改变预测下一个词元的目标。

表 5 比较“先预训练再微调”与“不预训练、直接在任务上训练”：八项任务的无权重平均分由前者的 74.7 降至后者的 59.9。该消融支持预训练提供了有用的任务学习起点，但不能单凭结果确定模型内部学到了哪些具体知识。
