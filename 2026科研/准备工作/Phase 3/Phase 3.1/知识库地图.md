# 知识库地图

本项目围绕 GPT1、GPT2 与 GPT3 论文学习生成式预训练：GPT1 研究“预训练后如何用标注数据微调”，GPT2 研究“仅靠语言建模，能否从自然文本示范中学会任务”，GPT3 则系统比较模型规模与零、单、少样本上下文示范的关系。地图按研究问题、方法、实现与证据组织，正文笔记、原始文献、图片和项目规则分别列出。

## 建议阅读顺序与逻辑链条

### GPT1：预训练 → 有监督微调 → 多任务适配

1. **先看全貌**：[[GPT1论文总结]]。
2. **分清训练阶段**：[[生成式预训练与判别式微调的区别]]，结合 [[GPT1的数据集用途与训练阶段]]。
3. **深入训练过程**：[[生成式预训练]]；需要理解微调中的联合训练时，再看 [[GPT1微调的辅助语言建模目标]]。
4. **看任务如何落地**：[[GPT1的文本蕴含相似度与问答任务]]，从输入、标注与输出理解各项应用。
5. **理解模型计算**：[[GPT1模型架构]]；前馈网络中的激活函数进一步见 [[GELU激活函数]]。
6. **回到证据并自测**：核对论文的实验与消融，再使用 [[GPT1论文理解自测12问与参考答案]]。

训练笔记解释“怎样学习”，架构笔记解释“怎样计算”，任务笔记解释“判断什么”。具体定义与公式在对应专题维护，论文总结只提供全貌。

### GPT2：自然文本示范 → 语言建模 → 无任务微调的迁移

1. **先建立全貌**：[[GPT2论文总结]] 保留研究问题、方法选择、代表性结果与局限的连续解释；专题承载详细知识，阅读时可按需要展开。
2. **理解学习与迁移**：以 [[生成式预训练]] 为训练前置，读 [[语言模型如何从文本中学习多任务]] 理解自然任务示范，再用 [[Zero-Shot与Few-Shot]] 分清提示示范与参数更新。
3. **看方法怎样落地**：沿“材料 → 输入 → 模型”读 [[GPT2的WebText数据集]]、[[字节级BPE分词]]、[[GPT2模型架构]]，对照 [[Language Models are Unsupervised Multitask Learners_完整中文翻译#2 方法|译文第 2 节]]；Transformer 基础需要时再看 GPT1 架构笔记。
4. **用实验判断能力**：先用 [[语言模型与生成任务的评估指标]] 理解分数，再读 [[GPT2的任务设置与实验结果]] 的输入、输出规则、图表与错误；区分语言建模的“7/8”与其他任务的有限表现。
5. **检查证据边界**：[[GPT2的规模效应与欠拟合]] 解释扩容的经验收益，[[GPT2的数据重叠与文本记忆]] 检查污染与记忆；结合实验专题的附录生成样例，区分未挑选样本、挑选样本与真实可靠性。
6. **独立回答并核验**：[[GPT2论文理解自测12问与参考答案]] 用 12 问覆盖整篇论文；它也嵌入译文末尾，以独立笔记为唯一答案维护源。

三篇论文共享语言建模预训练与同类模型主体。GPT1 的目标任务适配依赖有监督参数更新；GPT2 主要研究无需任务微调的迁移；GPT3 保持评估时参数固定，系统比较上下文中的示范数量与模型规模。各篇总结保留论证主线，专题维护独立知识与详细证据；GELU 等底层专题按具体计算需要进入阅读路径。

### GPT3：扩大预训练模型 → 上下文示范 → 跨任务评估与证据核验

1. **先看研究主线**：[[GPT3论文总结]] 解释为何扩大模型、少样本怎样使用、代表性结果与失败边界。
2. **分清学习发生在哪里**：先读 [[Zero-Shot与Few-Shot]]，再用 [[GPT3的上下文学习与评估方法]] 核对示范、候选评分、自由生成及开发／测试集口径。
3. **理解模型与训练**：[[GPT3模型架构]] 解释八种模型与交替注意力；[[GPT3的训练数据与训练过程]] 解释数据过滤、混合采样、文档打包和优化。输入表示复用 [[字节级BPE分词]]，预训练目标复用 [[生成式预训练]]。
4. **按任务判断收益与失败**：[[语言模型与生成任务的评估指标]] 提供指标前置，[[GPT3的任务设置与实验结果]] 保存各基准的设置、结果和边界；[[GPT3的合成任务与文本生成]] 单独解释算术、字符操作、类比、新闻、新词和语法例子。
5. **检查污染与推断范围**：[[GPT3的基准污染与记忆分析]] 解释检测程序、干净／污染子集及六类特别调查；[[GPT3的局限与社会影响]] 解释可靠性、偏差和误用研究的条件。
6. **独立作答并回查原文**：[[GPT3论文理解自测12问与参考答案]] 检查机制与证据，[[Language Models are Few-Shot Learners_完整中文翻译]] 提供全部正文和附录，原文矛盾在对应位置以译注说明。

GPT3 的算术、文本生成、人类新闻判断与偏差分析各有自己的任务规则，不能仅凭同属语言模型就相互替代证据。附录 G 保存任务格式与标准答案，附录 H 保存各规模、各设置结果，分别用于核对输入和分数。
