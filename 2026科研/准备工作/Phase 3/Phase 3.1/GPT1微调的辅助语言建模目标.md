# GPT1微调的辅助语言建模目标

**辅助目标是在任务微调时，继续根据前文预测真实的下一个词元。**它和任务目标一起更新模型，作用于任务数据的文本 $C$，不是重新完整执行一次 BooksCorpus 预训练。

## 一个例子

任务样本为文本“这部电影很好看”，标签为“正面”。主目标要求模型根据输入预测正面标签；辅助目标要求模型利用文本前缀预测后续词元。示意上可以用“这部电影很好”预测“看”，实际目标以分词器产生的词元为单位。

| 比较项 | 主目标 | 辅助目标 |
| --- | --- | --- |
| 预测对象 | 任务标签、分数或候选答案 | 文本中真实的后续词元 |
| 答案来源 | 人工任务标注 | 输入文本自身 |
| 典型输出层 | 新增任务输出层 | 语言模型输出投影 |
| 在微调中的作用 | 适配具体任务 | 同时保留语言建模训练信号 |

辅助目标的答案来自输入文本，而不是额外的问答标签或模型生成的解释。

## 如何组合目标

论文最大化对数似然目标：

$$
L_3(C)=L_2(C)+\lambda L_1(C).
$$

其中，$L_2$ 是任务监督对数似然，$L_1$ 是任务文本的语言建模对数似然。若改写为最小化负对数似然损失，则为：

$$
\mathcal L_{\mathrm{总}}=\mathcal L_{\mathrm{任务}}+\lambda\mathcal L_{\mathrm{语言模型}}.
$$

反向传播时，共享模型主体同时接受两项损失的梯度：

$$
\nabla_\Theta\mathcal L_{\mathrm{总}}=\nabla_\Theta\mathcal L_{\mathrm{任务}}+\lambda\nabla_\Theta\mathcal L_{\mathrm{语言模型}}.
$$

论文设定 $\lambda=0.5$，表示辅助项的目标权重，不等于它贡献一半性能或一半参数更新；实际影响还取决于各项损失及梯度规模。$\lambda=0$ 时去掉辅助项，但仍可以保留预训练得到的初始化参数。

## 有什么作用，是否一定有效

第 3.2 节报告，辅助目标有助于改善泛化和加快收敛。可以将其理解为：在学习具体任务的同时，仍让参数满足一定的文本预测要求。这是对联合训练作用的解释，不是论文已直接证明模型避免遗忘某项能力的证据。

表 5 的消融结果表明，辅助目标不是普遍有效：

| 指标或任务 | 带辅助目标 | 不带辅助目标 |
| --- | ---: | ---: |
| CoLA（MCC） | 45.4 | 47.9 |
| SST-2（准确率） | 91.3 | 92.0 |
| MRPC（F1） | 82.3 | 84.9 |
| STS-B（Pearson 相关） | 82.0 | 83.2 |
| QQP（F1） | 70.3 | 69.8 |
| MNLI（准确率） | 81.8 | 81.1 |
| QNLI（准确率） | 88.1 | 86.9 |
| RTE（准确率） | 56.0 | 54.4 |
| 八项无权重平均分 | 74.7 | 75.0 |

辅助目标对表中的 NLI 任务和 QQP 有帮助，对另外四项没有提高分数，整体平均分也略低。作者提出较大数据集更可能受益的趋势判断，但不能将其当作无例外的规则，也不能将不同任务的评价指标理解为同一种准确率。

> [!important] 两种消融不能混为一谈
> **去掉辅助目标**：仍先预训练，只在微调时不再计算语言建模项。  
> **去掉预训练**：不使用预训练初始化，直接进行任务训练。  
> 两阶段的整体关系见 [[生成式预训练与判别式微调的区别]]。
