# GPT1的下游任务与输入变换

> [!abstract] 这篇笔记回答什么
> GPT1 微调后能完成哪些任务？每类任务输入什么、预测什么、用什么答案训练？结构化输入如何转换成同一个模型能处理的词元序列？

## 共同机制与任务全貌

**判别式微调根据输入预测任务结果。** 输入经过预训练 Transformer，任务输出层产生预测，再与标注的类别、分数或正确选项比较，计算损失并更新模型主体和输出层。结果可以是类别、连续分数或候选答案，不限于情感分类。

论文在四类任务、共 12 个数据集上进行监督微调评估。各任务分别适配预训练模型，并不是依次训练所有任务后得到一个通用聊天助手。

| 大类 | 判断的问题 | 数据集 | 输出形式 |
| --- | --- | --- | --- |
| 文本分类 | 一段文字属于什么类别？ | SST-2、CoLA | 情感或语法可接受性标签 |
| 自然语言推断 | 前提是否支持假设，或句子是否包含问题答案？ | SNLI、MultiNLI、RTE、SciTail、QNLI | 数据集规定的关系标签 |
| 句子相似度 | 两句话是否等价，或有多接近？ | MRPC、QQP、STS-B | 复述标签或连续相似度分数 |
| 问答与常识推理 | 哪个候选答案或结局最合理？ | RACE、Story Cloze | 候选答案上的概率与选择结果 |

以下例子均为自编教学示例，不是数据集原题。中文用来说明任务；论文评估的这些基准主要是英语数据。输入示意中的“开始”“分隔”“结束标记”表示特殊词元的功能，不是要输入这些中文字。分号表示拼接，也不代表插入文字分号。

## 1. 文本分类：给一段文字打标签

### 结束标记与图中的Extract

论文第 3.3 节把输入末尾的特殊词元称为结束词元 $\langle e\rangle$，图 1 中对应位置标为 **Extract（提取）**。此前笔记中的“结束/提取”表示同一末端位置的两个功能描述，不是要添加两个词元；下文统一使用“结束标记”。

```text
开始标记 → 文本或结构化任务输入 → 结束标记
                                   ↓
                        读取该位置的顶层表示
                                   ↓
                              任务输出层
```

“结束”说明特殊词元位于任务输入末尾，“提取”指读取该位置的向量。模型为各位置计算表示，任务输出层使用末端的 768 维顶层向量；这个位置能够通过因果注意力利用前面的输入，但不保证完美概括全部内容。标记自身的嵌入与经过网络得到的上下文表示也不是同一个向量。

这里既不是从文章里抽取答案文字，也不是要求模型生成结束词元。它描述的是任务微调时的输入组织与表示读取。

### 单句输入

**输入方式：**`开始 → 文本 → 结束标记`。取序列末端表示，通过任务输出层预测类别；正确类别就是监督信号。

### 情感分类：SST-2

| 输入文本 | 正确标签 |
| --- | --- |
| 剧情拖沓，表演也很生硬。 | 负面 |
| 情节紧凑，我愿意再看一次。 | 正面 |

这里训练的是正面/负面二分类，不是让模型生成影评。

### 语法可接受性：CoLA

| 输入文本 | 正确标签 | 判断依据 |
| --- | --- | --- |
| The boy is running. | 可接受 | 主语与动词一致 |
| The boy are running. | 不可接受 | 主语与动词不一致 |

CoLA 判断句子是否符合语言的语法规则；语法正确不等于事实正确或内容合理。

## 2. 自然语言推断：判断有方向的支持关系

前提 $p$ 是给定信息，假设 $h$ 是待判断的陈述。**输入方式：**`开始 → 前提 p → 分隔 → 假设 h → 结束标记`。末端表示用于预测关系，标注的关系类别提供监督。

蕴含有方向：“一只狗在奔跑”支持“一只动物在运动”，反过来不能确定动物是狗。因此不能把它简单理解为句子相似度。这里判断语句间的支持关系，不是在调查前提是否真实发生。

### 三分类推断：SNLI、MultiNLI

固定前提：“两名学生正在教室里讨论。”

| 假设 | 正确关系 | 含义 |
| --- | --- | --- |
| 有人在室内交谈。 | 蕴含 | 前提支持假设 |
| 教室里没有人。 | 矛盾 | 与前提冲突 |
| 这两名学生明天要考试。 | 中立 | 信息不足，无法确定 |

**中立不是“假设为假”。** 它只说明前提不足以确定假设。

### 二分类蕴含：RTE、SciTail

并非所有推断数据集都采用上面的三类标签。RTE 判断蕴含/非蕴含；SciTail 使用蕴含/中立标签。

| 数据集 | 前提 | 假设 | 正确标签 |
| --- | --- | --- | --- |
| RTE | 公司宣布在上海开设新的办公室。 | 公司在中国扩展办公地点。 | 蕴含 |
| RTE | 公司宣布在上海开设新的办公室。 | 公司关闭了所有中国办公室。 | 非蕴含 |
| SciTail | 金属受热通常会膨胀。 | 加热通常使金属体积增大。 | 蕴含 |
| SciTail | 金属受热通常会膨胀。 | 金属受热后质量一定增大。 | 中立，即前提不支持 |

输入结构相同，任务输出层的类别设置随数据集变化。

### 问题—句子分类：QNLI

QNLI 将阅读问答转成句子对分类，判断配对句子是否包含问题答案。示意输入为：`开始 → 问题 → 分隔 → 句子 → 结束标记`。

固定问题：“谁发现了青霉素？”

| 配对句子 | 正确标签 |
| --- | --- |
| 弗莱明发现了青霉素。 | 蕴含／包含答案 |
| 青霉素是一类抗生素。 | 非蕴含／不包含答案 |

**它输出关系标签，不是生成“弗莱明”，也不是抽取答案位置。**问题和句子的角色不同，不能当成对称相似度任务。

## 3. 句子相似度：处理无内在顺序的句子对

### 共同输入方式：两个顺序的表示相加

相似度通常希望满足交换对称性：A 与 B 的相似度应与 B 与 A 相同。GPT1 的因果序列处理受顺序影响，因此用同一个模型分别处理：

```text
开始 → A → 分隔 → B → 结束标记 → 表示 r_AB
开始 → B → 分隔 → A → 结束标记 → 表示 r_BA
```

在送入任务输出层之前，逐元素相加：

$$
r=r_{AB}+r_{BA}.
$$

例如 $[1,2,3]+[4,5,6]=[5,7,9]$。相加的是**表示向量**，不是文字或预测概率。在不含训练时 dropout 随机性的确定性计算中，交换 A、B 只是交换两个加数，总表示保持不变。

### 复述检测：MRPC

判断两句话是否表达基本相同的意思，监督信号是“复述/非复述”标签。

固定句子 A：“公司计划明年增加员工。”

| 句子 B | 正确标签 |
| --- | --- |
| 公司打算在下一年扩招。 | 是复述 |
| 公司明年将减少员工。 | 不是复述 |

相同词语多不代表意思相同；否定、人物角色和动作方向都会影响判断。

### 重复问题检测：QQP

判断两个问题是否具有相同的求解意图，监督信号是“重复/非重复”标签。

固定问题 A：“怎样提高英语口语？”

| 问题 B | 正确标签 |
| --- | --- |
| 如何提升英语口语水平？ | 重复问题 |
| 如何提高英语阅读速度？ | 非重复问题 |

同属英语学习主题，不足以认定为重复问题。

### 连续相似度评分：STS-B

STS-B 的人工相似度尺度为 **0–5**，微调学习预测连续分数。正确分数提供监督；它不是简单二分类。

固定句子 A：“一个男人正在弹吉他。”

| 句子 B | 预期相似程度 |
| --- | --- |
| 一名男子正在演奏吉他。 | 很高 |
| 有人正在演奏乐器。 | 较高，细节不完全相同 |
| 一只狗正在草地上奔跑。 | 很低 |

以上只说明高低，没有给自编示例指定官方分值。相加后的表示由任务输出层产生评分；不能把第 3.2 节的分类 softmax 公式机械套用到所有任务，论文正文也未逐项详述回归实现。

## 4. 问答与常识推理：比较候选答案

### 共同输入方式：一个候选对应一条序列

给定背景 $z$、问题 $q$ 和候选答案 $a_k$，分别构造 $[z;q;\$;a_k]$：

```text
开始 → 背景 → 问题 → 分隔 → 候选 A → 结束标记
开始 → 背景 → 问题 → 分隔 → 候选 B → 结束标记
```

同一个模型分别计算末端表示，输出层产生候选分数 $s_k$，再在候选间做 softmax：

$$
P(a_k\mid z,q)=\frac{\exp(s_k)}{\sum_j\exp(s_j)}.
$$

若 $s_A=1$、$s_B=3$，概率约为 $0.119$、$0.881$，模型选择 B。这只是数值示意。正确选项提供监督，训练鼓励它获得更高概率；softmax 只负责归一化，答案判断能力来自模型和训练。

### 选择题阅读理解：RACE

#### 两道题各四个选项 是否重复文章八次

**按论文这种输入构造方式，是的：两道题各四个候选，共构造八条序列，文章在每条中都出现。**

```text
文章 + 问题1 + 分隔 + 选项A → 分数1A
文章 + 问题1 + 分隔 + 选项B → 分数1B
文章 + 问题1 + 分隔 + 选项C → 分数1C
文章 + 问题1 + 分隔 + 选项D → 分数1D

文章 + 问题2 + 分隔 + 选项A → 分数2A
文章 + 问题2 + 分隔 + 选项B → 分数2B
文章 + 问题2 + 分隔 + 选项C → 分数2C
文章 + 问题2 + 分隔 + 选项D → 分数2D
```

示意省略开始与结束标记。问题 1 的四个候选分数单独做 softmax，问题 2 也单独做 softmax，各选一个答案；不是在八个分数之间选出一个答案。

这里区分三个层次：

| 层次 | 含义 |
| --- | --- |
| 输入内容 | 文章重复出现在八条候选序列中 |
| 模型调用 | 可以把多条序列组成批次计算，不一定单独调用八次 |
| 计算复用 | 批处理并不自动消除公共前缀的重复计算；共享前缀缓存需要额外实现，论文这一节未说明采用该优化 |

这种设计用统一序列评分适配选择题，代价是内容与计算重复。它描述的是 GPT1 的任务输入，不要求现代聊天用户把文章粘贴八遍。实际处理还受序列长度及截断规则影响，不能据此断定任意长文章都完整重复输入。

#### 单题示例

> 文章：因暴雨，比赛从周六推迟到周日。已购买的门票仍然有效。  
> 问题：比赛将在哪一天举行？  
> A：周五；B：周六；C：周日；D：周一。  
> 正确答案：C。

RACE 根据英语文章选择给定答案，**不是自由生成答案**。这个例子依靠明确的文本信息，实际任务也可能要求整合多个句子并推理。RACE-m 和 RACE-h 是初中、高中考试部分，属于同一个数据集的不同部分。

### 故事结局选择：Story Cloze

> 小林忘带钥匙，发现家门锁着。他给同住的姐姐打了电话。姐姐说自己马上到家。  
> A：姐姐回来帮他开了门。  
> B：小林把电话变成钥匙打开了门。  
> 正确结局：A。

将故事分别与两个候选结局拼接，可以没有独立问题 $q$。除了文本线索，还需要连贯性判断和日常常识。本例的错误选项刻意明显，真实任务可能更难。

## 微调、辅助目标与零样本的边界

- **这里的输入变换用于有监督微调。**添加分隔词元不会自动教会模型判断，任务标签或分数才提供对应监督。预训练语料与任务数据的区别见 [[GPT1的数据集用途与训练阶段]]。
- **辅助语言建模目标是额外的词元预测。**启用时，除上述任务监督外，再用输入文本自身训练下一个词元预测；它不改变各任务的标签含义。详见 [[GPT1微调的辅助语言建模目标]]。
- **论文第 5 节另做零样本分析。**例如 RACE 用语言模型对候选答案的平均词元对数概率进行启发式选择，没有该任务的监督微调，与这里训练候选评分层的流程不同。DPRD 的 Winograd 指代解析属于零样本分析，不在上述 12 个监督任务数据集内。

这些输入变换的目的，是让有角色、顺序或候选结构的文本复用同一个模型主体，只对输入组织和任务输出作少量适配。主体计算结构见 [[GPT1模型架构]]。
