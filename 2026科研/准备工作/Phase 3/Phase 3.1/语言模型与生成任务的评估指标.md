# 语言模型与生成任务的评估指标

**先明确评测单位、输出规则与指标，才能理解模型分数。**本笔记汇总阅读 GPT2、GPT3 实验时需要的指标含义，并解释为什么不同分词单位或不同任务的分数不能直接比较；这里是入门说明，精确计算应遵循各基准的评估实现。

## 各项指标在衡量什么

不同任务的分数不能直接横向比较：55 F1 不是 55% 问题完全答对，11.5 BLEU 也不是 11.5% 句子翻译正确。

| 指标 | 大致在衡量什么 | 越大还是越小越好 |
| --- | --- | --- |
| PPL，困惑度 | 模型给真实文本分配概率的好坏 | 越小越好 |
| BPB，bits per byte | 平均预测一个字节所需的比特数 | 越小越好 |
| BPC，bits per character | 平均预测一个字符所需的比特数 | 越小越好 |
| Accuracy | 样本或选项答对的比例 | 越大越好 |
| 问答 F1 | 与参考答案的词元重合所得到的精确率、召回率的综合 | 越大越好 |
| ROUGE-1、2、L | 分别衡量摘要与参考摘要的单词、连续两词和最长公共子序列重合 | 越大越好 |
| BLEU | 译文与参考译文的 n-gram 匹配等 | 越大越好 |
| Exact Match，EM | 答案经评估规则处理后是否完全匹配参考答案 | 越大越好 |

## 困惑度及规范单位

困惑度可概括为：

$$
\operatorname{PPL}=\exp\left(-\frac{1}{U}\log p_\theta(x)\right),
$$

其中 $x$ 是评估文本，$\theta$ 是模型参数，$p_\theta(x)$ 是模型为整段文本分配的概率；$U$ 是评测所用的规范单位数量，在词级报告中是词数。BPB/BPC 则使用以 2 为底的负对数，并分别除以字节数/字符数。

**GPT2自身的 BPE 词元数与评测数据的规范词数不一定相同。** 作者通过计算整个数据集的对数概率，再除以相应规范单位来比较结果。因此，不能简单把某种分词器下的“每词元困惑度”拿来和另一种分词器下的数值直接比较。

## 可逆反分词为什么影响分数

GPT2 论文还对一些数据集使用可逆的去分词处理，尽量还原被拆开的标点、缩写等。原文称这可视为一种简单领域适配，为 GPT2 带来约 2.5–5 个困惑度的改善。这不是重新训练参数，但确实是会影响结果的输入处理。
